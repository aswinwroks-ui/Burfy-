# BURFY — Flutter poster editor prototype

An independent, BURFY-inspired Flutter design editor with regional-language presets, movable text and artwork layers, templates, local saves, image import and PNG export.

**Android APK:** Open [Actions](https://github.com/aswinwroks-ui/Burfy-/actions) and select the latest successful **Build BURFY Android APK** workflow. Download the `BURFY-Android-APK` artifact and unzip it to get `BURFY-demo.apk`.

This is an independent prototype, not the official BURFY app. AI illustration generation is mocked/offline, not a live AI service.

Flutter source is imported by the APK build workflow and published into this repository after a successful build.
